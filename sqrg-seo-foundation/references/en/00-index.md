# 00 · Reference File Index

**Source:** Google Search Quality Rater Guidelines ("General Guidelines"), **September 11, 2025** edition, 182 pages. As of October 2026 this is still the edition Google publishes (see `13-changelog.md`).

**Nature of the content:** every file is rewritten and condensed in our own words, not Google's text. Section and page numbers are given so points can be checked against the original PDF. Sections labeled **[Application]** are added notes for SEO/content practice, not SQRG content.

**Two languages:** `references/en/` (English) and `references/id/` (Indonesian) hold files with the same names, section order and page references. Both are equivalent; pick one when working.

## Intentionally not summarized

These sections cover raters' internal work procedures and aren't relevant to SEO:
- 0.2–0.5 (p. 7): raters representing their locale, browser requirements, ad blockers, internet safety.
- 10.1 (p. 91): PQ task interface details (only briefly summarized in `07`).
- 15.3 (p. 146): procedure for reporting illegal images.
- Appendix 1 (pp. 175–181): using the evaluation platform (acquiring, rating, releasing tasks, reporting duplicates, simplified Needs Met tasks).

## About the images in the PDF

- Part 1 examples (PQ): the embedded images are only **rating sliders**; page screenshots are external links, so the explanatory text already carries each example's substance.
- Parts 2 and 3: images are **illustrations** (e.g., stick figures with thought bubbles for locale and intent, person-icon diagrams for query interpretations) and **SERP result-block screenshots**. The important ones are described in `08`, `09` and `10`.
