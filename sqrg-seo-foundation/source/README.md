# Folder source/

Folder ini disediakan untuk **PDF asli SQRG** jika kamu ingin skill bisa mengecek redaksi persis dari Google.

PDF tidak disertakan dalam paket skill karena dokumen itu milik Google (ber-hak cipta). Cara menambahkannya:

1. Unduh PDF "Search Quality Rater Guidelines" langsung dari situs resmi Google (edisi yang dipakai skill ini: 11 September 2025).
2. Simpan dengan nama `sqrg-2025-09-11.pdf` di folder ini.
3. Jika memasang skill lewat file `.skill`, ekstrak dulu, tambahkan PDF ke folder `source/`, lalu kemas dan pasang ulang. Alternatifnya, upload PDF di percakapan saat butuh redaksi persis.

Tanpa PDF ini skill tetap berfungsi penuh; file di `references/` sudah memuat isi yang dibutuhkan beserta rujukan halaman.
